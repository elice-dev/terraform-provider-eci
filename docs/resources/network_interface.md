# eci_network_interface (Resource)

Manages an ECI network interface (NIC). A NIC connects a virtual machine to a subnet, providing the VM with a private IP address.

## Example Usage

```terraform
resource "eci_network_interface" "my_nic" {
  name                = "my-nic"
  attached_subnet_id  = eci_subnet.my_subnet.id
  attached_machine_id = eci_virtual_machine.my_vm.id
  dr                  = false
  tags = {
    "created-by" = "terraform"
  }
}
```
